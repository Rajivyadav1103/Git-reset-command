git reset command

The git reset command is used to undo changes in the Git repository. It can be used to move the HEAD pointer to a specific commit, effectively changing the current branch's history. The git reset command has three main options: --soft, --mixed, and --hard.

git reset --soft

Usage:

git reset --soft <commit>

This option moves the HEAD pointer to the specified commit, but it does not change the index or the working directory. This means that any changes made after the specified commit will be staged for commit.

git reset --mixed
